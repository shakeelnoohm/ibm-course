# IBM Certified Full Stack JavaScript Developer Course Projects

This repository contains 11 hands-on JavaScript projects covering fundamental to intermediate concepts including DOM manipulation, events, debugging, array methods, fetch API, and form handling.

## Projects Overview

| Project | Description | Key Concepts |
|---------|-------------|--------------|
| **DebugCode** | Debugging exercise with number multiplication | Chrome DevTools, debugger statement |
| **TodoList** | Task management with add, toggle, and clear | Arrays, DOM manipulation, events |
| **bookSystem** | Book management with add/delete | Objects, arrays, form handling |
| **colorfulMemoryGame** | Card matching memory game | Game logic, timers, CSS manipulation |
| **employeeDetails** | Employee search and filter | map(), filter(), reduce(), find() |
| **followersCount** | Interactive follower counter | Events, alerts, conditional logic |
| **healthArticle** | Fetch and display health articles | fetch API, JSON, dynamic content |
| **productSurvey** | Product feedback form | Form validation, event handling |
| **restaurantMenu** | Menu display with iteration | map(), forEach(), for loops |
| **speedAnalysis** | Typing speed test | Date object, calculations, input handling |
| **weatherReport** | Live weather data display | fetch API, external API integration |

---

## How to Run

Each project is self-contained with an HTML file and JavaScript file.

1. Navigate to any project folder
2. Open the `.html` file in a web browser
3. No build tools or dependencies required!

For projects requiring external API (Weather Report), an API key is already included.

## Project Details

### 1. DebugCode
Simple debugging exercise where two numbers are multiplied. Demonstrates using the Chrome DevTools debugger statement.

**Files:** `debug_code.html`, `debug_code.js`

---

### 2. TodoList
A functional todo list where users can:
- Add new tasks
- Mark tasks as complete/incomplete
- Clear completed tasks
- Clear all tasks

**Files:** `todo_list.html`, `todo_list.js`

---

### 3. bookSystem
Book management system where users can:
- Add books with name, author, description, and page count
- View all books
- Delete the first book in the list

**Files:** `book_system.html`, `book_system.js`

---

### 4. colorfulMemoryGame
Interactive memory matching game with:
- 12 colored cards (6 pairs)
- 30-second timer
- Score tracking
- Match detection

**Files:** `colorful_memory_game.html`, `colorful_memory_game.js`, `colorfulGame.css`

---

### 5. employeeDetails
Employee management demo with buttons to:
- Display all employees
- Calculate total salaries
- Filter HR department employees
- Find employee by ID
- Find employee by specialization

**Files:** `employee_details.html`, `employee_details.js`

---

### 6. followersCount
Simple interactive counter with congratulatory alerts at 10 and 20 followers.

**Files:** `followers_count.html`, `followers_count.js`

---

### 7. healthArticle
Fetches health articles from a local JSON file and displays them dynamically with:
- Title and description
- Ways to achieve
- Health benefits

**Files:** `health_article.html`, `health_article.js`, `health_article.json`

---

### 8. productSurvey
Luxury brand feedback form that:
- Collects user information
- Validates required fields
- Displays submitted feedback

**Files:** `product_survey.html`, `product_survey.js`

---

### 9. restaurantMenu
Restaurant menu display demonstrating three iteration methods:
- `map()` for breakfast items
- `forEach()` for main course items
- `for` loop for dessert items

**Files:** `restaurant_menu.html`, `restaurant_menu.js`

---

### 10. speedAnalysis
Typing speed test that calculates:
- Words typed
- Time elapsed
- Words Per Minute (WPM)

**Files:** `speed_analysis.html`, `speed_analysis.js`

---

### 11. weatherReport
Live weather application using OpenWeatherMap API:
- Enter any city name
- Displays temperature and weather conditions
- Error handling for invalid cities

**Files:** `weather_report.html`, `weather_report.js`
